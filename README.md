# AI Learning 🚀

Welcome to the **AI Learning** repository! This repository documents a hands-on journey through Python programming, data analysis, visualization, and mathematical foundations for AI and Data Science.

---

## 📌 Daily Breakdown & Curriculum

| Day | Topic | Highlights / Mini Projects |
|---|---|---|
| 📖 **Day 1** | **Python Intro & Basic I/O** | Welcome scripts, basic inputs (`name`, `age`, `college`) and string formatting. |
| 📖 **Day 2** | **Data Types & Practical Apps** | BMI Calculator, Temperature Converter (Celsius to Fahrenheit), Student Profile builder, Basic Arithmetic Calculator. |
| 📖 **Day 3** | **Conditional Logic & Decision Making** | Voting Eligibility, Number Comparisons, Grade Evaluation, Heart Rate Monitor, and an Interactive ATM Banking System. |
| 📖 **Day 4** | **Loops & Iteration** | Multiplication Tables, Summation Series, Factorial Calculation, Pattern Printing (Star pyramids), and Password Attempt Security logic. |
| 📖 **Day 5** | **Modular Functions** | Functions with parameters & return values, Modular Calculator, Even/Odd verifier, 5-Subject Student Mark & Average Calculator. |
| 📖 **Day 6** | **Lists & Sequence Processing** | List manipulation, indexing, appending, list-based average calculator, pass/fail filter, even/odd number extractors. |
| 📖 **Day 7** | **Dictionaries & Data Mapping** | Key-value store operations, grade lookup system, dictionary update routines, and list-of-dictionaries batch iteration. |
| 📖 **Day 8** | **Dictionary Processing & Transformations** | Dynamic dictionary modification routines, bulk grade assignment function (`add_grade`). |
| 📖 **Day 9** | **Data Analysis Foundation** | Data analysis over student datasets (list of dictionaries), pass/fail counting, average calculation, highest/lowest mark identification. |
| 📖 **Day 10** | **Complete Student Data Analysis System** | Full-fledged Student Analytics Tool featuring grade calculation, top/lowest scoring student tracking, pass/fail counts, and formatted summary reporting. |
| 📖 **Days 11–13** | **Student Data Practice** | Filtering student records, identifying failed and high-performing students, and calculating summary statistics. |
| 📖 **Days 14–20** | **NumPy Fundamentals** | Arrays, Boolean filtering, two-dimensional datasets, arithmetic, scoring, and normalization. |
| 📖 **Days 21–27** | **Pandas Fundamentals** | DataFrames, data selection and analysis, grouping, feature engineering, and categorical mapping. |
| 📖 **Days 28–31** | **Working with Data Files** | Reading CSV and Excel datasets, analyzing student results, and handling missing values. |
| 📖 **Days 32–40** | **Data Visualization** | Matplotlib and Seaborn charts, including line, histogram, scatter, pie, heatmap, and box plots. |

## 📂 Repository Structure

- `day1.py`–`day40.py`: Daily Python, NumPy, pandas, and visualization exercises.
- `Mathematics for AI/`: Scripts and notes on probability, distributions, correlation, vectors, matrices, and shape.
- `csv files/` and `Excel files/`: Sample student datasets used by the data analysis exercises.
- `std_analysis.py` and the generated CSV/XLSX files: Student data analysis and outputs.
- `matplotlip.txt`, `num_formula.txt`, and `pandas_formula.txt`: Reference notes.
- `README.md`: Project overview and setup instructions.

## 🛠️ How to Run

Requirements: **Python 3.x**. The NumPy, pandas, visualization, and Excel lessons use third-party packages. Install them with:

```bash
python -m pip install numpy pandas matplotlib seaborn openpyxl
```

Run a script from the repository root using your terminal. For example:

```bash
python day14.py
python day29.py
python day40.py
```
