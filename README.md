# AI Learning 🚀

Welcome to the **AI Learning** repository! This repository documents a daily step-by-step hands-on journey through Python programming fundamentals, data structures, mini-projects, and analytical algorithms designed for AI and Data Science.

---

## 📌 Daily Breakdown & Curriculum

| Day | Topic | Highlights / Mini Projects |
|---|---|---|
| 📖 **Day 1** | **Python Intro & Basic I/O** | Welcome scripts, basic inputs (`name`, `age`, `college`) and string formatting. |
| 📖 **Day 2** | **Data Types & Practical Apps** | BMI Calculator, Temperature Converter (Celsius to Fahrenheit), Student Profile builder, Basic Arithmetic Calculator. |
| 📖 **Day 3** | **Conditional Logic & Decision Making** | Voting Eligibility, Number Comparisons, Grade Evaluation, Heart Rate Monitor, and an Interactive ATM Banking System. |
| 📖 **Day 4** | **Loops & Iteration** | Multiplication Tables, Summation Series, Factorial Calculation, Pattern Printing (Star pyramids), and Password Attempt Security logic. |
| 📖 **Day 5** | **Modular Functions** | Functions with parameters & return values, Modular Calculator, Even/Odd verifier, 5-Subject Student Mark & Average Calculator. |
| 📖 **Day 6** | **Lists & Sequence Processing** | List manipulation, indexing, appending, list-based average calculator, pass/fail filter, even/odd number extractors. |
| 📖 **Day 7** | **Dictionaries & Data Mapping** | Key-value store operations, grade lookup system, dictionary update routines, and list-of-dictionaries batch iteration. |
| 📖 **Day 8** | **Dictionary Processing & Transformations** | Dynamic dictionary modification routines, bulk grade assignment function (`add_grade`). |
| 📖 **Day 9** | **Data Analysis Foundation** | Data analysis over student datasets (list of dictionaries), pass/fail counting, average calculation, highest/lowest mark identification. |
| 📖 **Day 10** | **Complete Student Data Analysis System** | Full-fledged Student Analytics Tool featuring grade calculation, top/lowest scoring student tracking, pass/fail counts, and formatted summary reporting. |
